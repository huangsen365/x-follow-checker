# X Follow Checker

[![GitHub stars](https://img.shields.io/github/stars/huangsen365/x-follow-checker?style=social)](https://github.com/huangsen365/x-follow-checker)
[![GitHub issues](https://img.shields.io/github/issues/huangsen365/x-follow-checker)](https://github.com/huangsen365/x-follow-checker/issues)

A Chrome extension to check which accounts you follow on X.com (Twitter) don't follow you back.

[简体中文](./README.zh-CN.md) | [繁體中文](./README.zh-TW.md)

## Features

- **One-click detection** — Scan your entire following list
- **Mutual follow status** — See who follows you back and who doesn't
- **Bilingual UI** — Switch between English and Chinese
- **Export data** — Download results as CSV or JSON
- **Privacy-focused** — All data processed locally, no external servers

## Installation

1. Download or clone this repository
2. Open Chrome and go to `chrome://extensions/`
3. Enable **Developer mode** (toggle in top right)
4. Click **Load unpacked**
5. Select the `x-follow-checker` folder

## Usage

1. Log in to [x.com](https://x.com) in your browser
2. Click the extension icon in Chrome toolbar
3. Enter your X username
4. Click **Start Check**
5. View results — filter by All / Mutual / Not Following Back
6. Click any user to open their profile
7. Export results as CSV or JSON

## Requirements

- Google Chrome browser
- Logged in to X.com
